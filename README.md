# Atelier ACMG

A workbench for ACMG/AMP classification of germline variants, with automatic suggestions (interface in French).

**Open it:** https://clairevaltin.github.io/AtelierACMG/

## What it does

- Enter a variant and its mode of inheritance (AD, AR, X-linked)
- The **28 ACMG/AMP criteria** are shown as cards. Some are suggested automatically from Ensembl VEP, gnomAD, ClinVar, MobiDetails and SpliceAI. The others are left for you to answer.
- Apply, remove or change the strength of each criterion, following ClinGen SVI recommendations
- The class is computed with both the **ACMG 2015 combining rules** and the **Bayesian points system** (Tavtigian et al. 2020)
- **NMD prediction** for premature stop codons and a guided **PVS1 decision tree** (Abou Tayoun et al. 2018)
- **Export** a summary as text, JSON or a printable PDF
- A built-in guide explains every criterion, rule and data source

The tool suggests. You decide.

## How to use

Open the link above. Nothing to install.
